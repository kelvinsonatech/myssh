---
name: Website username prefixes
description: User-requested prefix support and total username length
---
Website-created usernames must support hyphenated prefixes and a maximum of
25 characters for the entire username, including its prefix. Preserve the exact
name rather than truncating it or removing separators.

**Why:** the user uses website prefixes to distinguish customers and avoid
collisions, and explicitly requested narrowly scoped changes without disrupting
protocols or settings.

**How to apply:** keep existing accounts unchanged and reject overlength new
names clearly. Prefix support does not mean allowing shell metacharacters or
changing the requirement to start with a lowercase letter.
